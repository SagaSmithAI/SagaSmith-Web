隐私说明

这份说明解释 SagaSmithAI 运营的 SagaSmith Web 托管服务处理哪些数据，以及你可以如何控制它们。自行部署者是其部署的数据运营方，应提供自己的说明。

我们处理的数据

账户资料包括邮箱、显示名称、密码的单向哈希、会话与条款接受记录。产品数据包括战役协作记录、消息、上传内容、Forge 作品、私有 Pack、Agent/模型用量、审核与安全审计事件。服务还会记录请求标识、错误、性能和安全日志。

用途与权威边界

数据用于登录、安全防护、协作、配额、恢复、内容审核和产品运行。D&D、CoC 与 Narrative 的权威游戏状态仍由相应 MCP/runtime 管理；Web 只保存云端工作流和经授权的投影。我们不会出售个人数据。

处理方与传输

你主动调用的模型提供商、对象存储、数据库、邮件或基础设施运营商可能按部署配置处理必要数据。私密消息和商业来源不会因使用 Forge 自动公开。向 Agent 或外部模型发送内容前，请避免放入不必要的个人或机密信息。

保留、安全与删除

会话、运行日志、备份、审计证据和协作内容会按安全、恢复、争议处理与法律需要保留不同期限。账户页可退出其他会话、改密或立即停用登录。访问、更正、导出或删除请求会在核实身份、共同作品、审计义务和权威战役记录后处理；删除不等于改写其他参与者依法保留的共同记录。

联系

隐私请求请发送到 mikewushuwen@gmail.com，主题注明“SagaSmith Privacy”。安全漏洞请使用 GitHub 私密漏洞报告，不要公开敏感证据。

变更

重要变更会更新日期；需要重新同意时，注册或账户流程会展示新版本。当前版本为 2026-08-29。
